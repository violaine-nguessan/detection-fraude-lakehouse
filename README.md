# detection-fraude-lakehouse

Objectif du projet : fournir des données de transactions par carte bancaire fiables et à jour, pour deux usages :
1.	une table de features qui permet aux data scientists d’entraîner un modèle de détection de fraude ;
2.	un schéma en étoile qui permet aux analystes antifraude de suivre la fraude dans un tableau de bord.
